🔐 Engineering Principles
I try to keep these principles in mind while building applications:
- Security first --- never trust the client for authorization or
  sensitive operations.
- Separation of concerns --- keep UI, business logic and data
  access understandable.
- Validate at the backend --- client-side validation is not a
  security boundary.
- Design APIs carefully --- predictable endpoints and meaningful
  HTTP status codes.
- Think about failure cases --- external services and networks can
  fail.
- Keep secrets out of source control --- use environment
  variables.
- Optimize based on evidence --- measure before adding unnecessary
  complexity.
